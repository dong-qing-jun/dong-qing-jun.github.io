通过ssh访问github

环境：本电脑系统是win10ltsc，shell采用powershell7。
其它系统步骤相同，但执行的命令各不相同（其它系统也可安装powershell7）

生成ssh密钥

ssh-keygen -t ed25519 -C "your_email@example.com"
  • 替换 your_email@example.com 为您的 GitHub 邮箱。
  • 按提示完成生成（直接回车使用默认路径）。

上面的命令输入完成后，弹出的选项全部默认，即直接回车，会生成两个文件 id_ed25519和id_ed25519.pub。其中id_ed25519.pub是公钥，谁都可以看，这个要放到github中。

查看ssh公钥

cat ~/.ssh/id_ed25519.pub

将会输出以ssh-ed25519开头的一串字符，包含了其它信息，但一整串都可以当作你的公钥，因为像github这样的平台会自动识别其中的真正公钥部分。

github添加公钥

1、 登录 GitHub → ​​Settings​​ → ​​SSH and GPG keys​​ → ​​New SSH key​​。
2、 粘贴公钥内容，保存。

​​测试 SSH 连接​

ssh -T git@github.com
  • 看到 You’ve successfully authenticated 表示成功。结束。
  • 若提示 Permission denied，继续下一步。

*密钥管理​​（可选）

New-Item -Path $env:USERPROFILE\.ssh\config -ItemType File -Force

在.ssh目录下创建一个config文件

notepad $env:USERPROFILE\.ssh\config

使用notepad编辑这个config文件

Host github.com
  HostName github.com
  IdentityFile ~/.ssh/github_key
  User git

然后再次测试

ssh -T git@github.com
